# TNH Studio React

React-basierte Website für TNH Studio (Tonstudio).

## Lokaler Entwicklungsserver

### Installation

```bash
npm install
```

### Server starten

```bash
npm run dev
```

Die Website ist dann verfügbar unter: http://localhost:3000/

### Build für Production

```bash
npm run build
```

### Preview des Production Builds

```bash
npm run preview
```

## Technologie-Stack

- React 18
- Vite
- React Router
- ESLint
